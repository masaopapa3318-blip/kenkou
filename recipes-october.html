No.01

キノコの和風マリネ

PHOTO

材料

  • キノコ400g
  • オリーブオイル30g
  • 醤油15g
  • リンゴ酢15g
  • みりん5g
  • 酒5g

作り方

  1. オリーブオイルを熱し、キノコをしっかりと焼き色がつくまで炒めます。
  2. 醤油、リンゴ酢、みりん、酒を計量して、よく混ぜておきます。
  3. ①でしっかりと焼き色をつけたキノコを、②に漬け込みます。

No.02

キノコのソテー

PHOTO

材料

  • キノコ500g
  • オリーブオイル35g
  • 塩3g
  • 黒胡椒0.5g
  • 醤油17g
  • 玉ねぎ（短冊切り）130g
  • ニンニク（刻み）4g

作り方

  1. オリーブオイルを熱してニンニクを入れ、しっかりと香りをつけます。
  2. 玉ねぎを加え、しんなりするまでしっかりと炒めます。
  3. キノコを加え、焼き色がつくまでしっかりと炒めます。
  4. 十分に炒めたら、塩、醤油、胡椒の順に加えて、さらに炒めます。

No.03

リンゴとサツマイモの柚子きんとん

PHOTO

材料

  • リンゴ（スライス・皮むき）200g
  • サツマイモ（スライス・皮むき）250g
  • 塩ひとつまみ
  • みりん15g
  • 水80g
  • 柚子の皮適量

作り方

  1. 鍋にスライスしたリンゴを並べ、その上にスライスしたサツマイモを重ねていきます。塩ひとつまみ、みりん、水を加えて蓋をし、柔らかくなるまでゆっくりと火を通します。
  2. 火が通ったら、マッシャーで潰します（水分はほぼない状態です）。焦げつかないように注意しながら煮詰め、ペースト状にしていきます。冷やしたら出来上がりです。
  3. お皿に盛り付け、柚子の皮を振りかけて提供します。

No.04

天然キノコのパテ

PHOTO

材料

  • 天然キノコ（スライス）300g
  • ニンニク6g
  • ココナッツオイル25g
  • 日本酒50g
  • 天然塩3g
  • 醤油3g
  • くるみ60g
  • 黒胡椒（しっかりめ）適量

作り方

  1. ココナッツオイルを鍋に入れ、ニンニクを加えて香りをつけます。
  2. 天然キノコのスライスを加え、炒めます。
  3. 日本酒を加え、さらに炒めます。
  4. くるみ、塩、醤油、胡椒を加えて全体をよくなじませ、火からおろします。
  5. 粗熱が取れたらラップをして、冷蔵庫で冷やします。十分に冷えたら、フードプロセッサーでペースト状にします。

No.05

天然キノコのスープ

PHOTO

材料

  • 天然キノコ660g
  • 玉ねぎ（スライス）195g
  • ニンニク（刻み）25g
  • オリーブオイル58g
  • 水4,680g
  • ローリエ4枚
  • 塩26g
  • 野菜だし26g
  • 黒胡椒適量

作り方

  1. オリーブオイルに刻んだニンニクを加え、香りをつけます。
  2. 玉ねぎのスライスを加え、しっかりと炒めます。
  3. 同じようにキノコを加え、しっかりと炒めていきます。
  4. キノコがしっかり炒まったら、水、ローリエ、塩、野菜だし、黒胡椒を加えて煮込んでいきます。
  5. 味を見ながら、足りないようでしたら黒胡椒をプラスしてみてください。

No.06

天然キノコ麹

PHOTO

材料

  • 天然キノコ300g
  • 麹100g
  • 天然塩25g
  • 水100g

作り方

  1. 天然キノコをスライスして、油なしで炒めていきます。
  2. 水を加えてよく混ぜ、60℃まで冷まします。
  3. 麹と塩をよく混ぜて、60℃に冷めた②に加え、60℃で8時間発酵させます。
  4. ペースト状にして、冷蔵保存します。

活用例

1即席簡単スープ

  • キノコ麹10g
  • お湯100g
  • キクラゲ（白・黒）お好みの量
  • 黒胡椒適量

これだけで簡単スープの出来上がり。お好みで、わかめや野菜を入れてもOKです。

また、キノコ麹はだしとしても活用できます。

No.07

椎茸のキノコスープ

PHOTO

材料

  • 乾燥椎茸（2,400gの水で戻す）22g
  • キノコ（エリンギ、しめじなど）140g
  • 玉ねぎ（スライス）90g
  • ニンニク20g
  • オリーブオイル30g
  • 椎茸の戻し水2,160g
  • ローリエ3枚
  • 天然塩14g
  • 野菜だし（お好みのだしで大丈夫です）16g
  • 黒胡椒適量
  • わかめ（千切り）適量

作り方

  1. 鍋にオリーブオイルを熱し、ニンニク、玉ねぎの順に加えて、しっかりと香りをつけながら炒めます。
  2. しっかりと絞った椎茸のスライスと、その他のキノコを加え、軽く焦げ目がつくまで炒めます。
  3. 戻し水、ローリエ、塩、野菜だしを加えてひと煮立ちさせます。アクが出るようならアクを取り、蓋をして15分程度煮込みます。
  4. 必要があれば塩・黒胡椒で味を整えます。器に盛り、わかめの千切りを散らして提供します。

No.08

柿と大根のサラダ

PHOTO

材料

  • 大根300g
  • 柿225g
  • 塩（大根の下ごしらえ用）適量
  • リンゴ酢22g
  • オリーブオイル22g
  • 蜂蜜7g
  • 白胡椒適量

作り方

  1. 大根を5cmくらいの短冊切りにして、袋に入れます。塩を適量入れてよくまぶし、軽く揉みます。10〜15分ほどそのまま置き、余分な水を出します。
  2. 柿は皮を剥いて、適当な大きさにスライス、または短冊切りにしておきます。
  3. ドレッシングを作ります。オリーブオイル、リンゴ酢、蜂蜜、白胡椒をよく混ぜておきます。
  4. 袋に穴を開けて、大根から出た水をしっかりと絞ります。袋から出して、大根と柿を混ぜ合わせます。ドレッシングを混ぜ込んで出来上がりです。

No.09

キノコそば

PHOTO

材料

  • かえし
  • 醤油50g
  • 無精製糖（キビラ）10g
  • みりん10g
  • 出汁スープ
  • 白だし20g
  • 水100g
  • かえし5g
  • 仕上げ
  • そば（お好みのもの）適量
  • キノコたっぷり

作り方

  1. かえしを作ります。醤油、無精製糖、みりんをよく混ぜて、沸騰させます。
  2. 白だしと水を混ぜて温めます。これにかえし5gを加え、温かいキノコそばの出汁スープにします。
  3. お好みのそばを茹でます。
  4. 温めた出汁の中にそばを入れ、キノコをたっぷり乗せていただきます。

No.11

じゃがいものガレット

PHOTO

材料（直径20cmのフライパン1枚分）

  • じゃがいも（せん切り）350g
  • 無精製糖（キビラ）4g
  • 天然塩1g
  • シュレッドチーズ40g
  • 片栗粉15g
  • 塩・白胡椒適量
  • オリーブオイル適量

作り方

  1. じゃがいものせん切り、無精製糖、天然塩を袋に入れてよく混ぜ、10〜15分ほど置きます。その間に、シュレッドチーズと片栗粉を用意しておきます。
  2. ①の袋から、じゃがいもの水分をしっかりと出します。
  3. じゃがいもにシュレッドチーズ、片栗粉を加えてよく混ぜます。その後、塩・白胡椒を適量加えます。
  4. オリーブオイルを熱した直径20cmのフライパンに生地を流し入れ、平らに押さえ込んでいきます。蓋をして約6分焼きます。
  5. 焼き色がついたらひっくり返し、もう片面も押さえながら焼き色がつくまで焼いたら出来上がりです。

No.12

キノコとサツマイモの炊き込みご飯

PHOTO

材料

  • お米2合（300g）
  • サツマイモ200g
  • マイタケ100g
  • しめじ100g
  • バター10g
  • 油揚げ1枚
  • 酒30g
  • みりん30g
  • 醤油30g
  • 水通常の2合分

作り方

  1. マイタケ、しめじを、しっかりと焼き色がつくまで炒めます。バターを加えて、さらに炒めます。天然のキノコがあれば、もっと良いです。
  2. サツマイモは、少し大きめの3cm角くらいに切り、水に晒しておきます。油揚げは縦半分に切り、1.5cm幅くらいに切っておきます。
  3. 酒、みりん、醤油を合わせて、よく混ぜておきます。
  4. お米をしっかりと研ぎ、③を加えて混ぜます。
  5. 通常の2合分の水を加え、①のキノコ、サツマイモ、油揚げを加えて、通常どおり炊飯します。

No.13

かぼちゃ餅

PHOTO

材料

  • かぼちゃ餅
  • かぼちゃ（皮を取って蒸す）500g
  • 片栗粉90g
  • ココナッツオイル10g
  • バター15g
  • 天然塩適量
  • タレ
  • 水45g
  • 蜂蜜30g
  • 醤油15g

作り方

  1. かぼちゃは皮を取って蒸します。蒸し上がったかぼちゃに片栗粉を加え、よく混ぜます。
  2. 40gずつに分割し、手水をつけながら円盤状に平たく成形します。
  3. ココナッツオイルを鉄板に敷き、成形したかぼちゃを並べて焼き色をつけていきます。焼き色がついたら、余分な油を拭き取ります。
  4. 両面こんがりと焼き色をつけたら、タレ（水・蜂蜜・醤油）を加えて煮絡めていきます。
  5. しっかりと水分が飛んで煮絡んできたら、バターを加えます。最後に天然塩を加えて味を調整したら出来上がりです。

栗ご飯

PHOTO

材料

  • 栗400g
  • 米（もち米を20%加えてもOK）3合（450g）
  • 塩5g

作り方
