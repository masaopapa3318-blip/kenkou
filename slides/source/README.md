# プレゼン資料の作成元データ

`slides/天給自足実践塾_未来創造プラン_リデザイン.pptx` を作るためのスクリプトと背景画像です。
次回のブラッシュアップ時に、ここから続きの作業ができます。

- `build.js` … スライドを生成するスクリプト（pptxgenjs）
- `dawn.jpg` … 章扉の「夜明け」背景
- `overlay_top.png` … 表紙・最後のスライドの写真に重ねるグラデーション

写真は、リポジトリ直下にアップロードされた元の .pptx ファイルから取り出して使っています（スクリプト内の `/root/work/img/`）。
フォントは BIZ UDPゴシック／BIZ UDP明朝 を使用しています。
