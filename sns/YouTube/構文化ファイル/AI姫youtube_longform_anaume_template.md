# YouTube長尺台本　穴埋め構文テンプレート

## AIへの指示

- このファイルと、コンテンツホルダーの資料（ナレッジ・実績・商品・ターゲット・リサーチ）を一緒に渡す
- 【 】は共通変数。最初に一度決めたら、全編で同じ言葉を使い回す
- ｛ ｝はその場の穴埋め。中の説明に従って埋める。「元：」は元動画での中身なので、そのまま使わず構造と強さだけ借りる
- ｛ ｝以外の地の文（強い言葉）は変えない。語尾だけ発信者の口調に合わせてよい
- 数字・実績・固有名詞・人の発言は、資料にある事実だけを使う。無ければ［要確認］と書いて空けておく（創作禁止）
- ブロックの順番は変えない。要素・工程・手順のブロックだけは数に合わせて増減してよい

## 構成の流れ

簡単に言うと
秘密暴露フック
⇓
悩みの言い当て → 脅威 → 反論先取り → 未来予言
⇓
ありがちな解決策の落とし穴 → 免責と安心
⇓
嫌われる警告 → 誤解の破壊 → ビフォーアフター
⇓
たったNステップ → 秘密性 → 段階モデル → 実績と再現性
⇓
ステップ1（要素を1つずつ：比喩・実演・落とし穴・反論処理）
⇓
トップ1%の正体 → ステップ2（工程ブロックの繰り返し）→ ステップ3
⇓
想いの吐露 → オファー → 特典の反論処理 → 一言まとめと分岐の問い

## 共通変数シート

- 【発信者名】チャンネルでの名乗り（元：AI姫）
- 【手段】視聴者に勧める解決手段（元：AI社員）
- 【中核ツール】手段を実現する具体ツール・方法（元：Claude Code）
- 【領域】視聴者が成果を出したい場（元：SNS）
- 【視聴者の呼び方】（元：発信者）
- 【理想の成果】視聴者が一番欲しい結果（元：バズる台本）
- 【悩みの症状】視聴者が今困っている具体的な症状（元：薄い台本が出てきて修正に時間がかかる）
- 【看板実績】冒頭で使う一番強い実績（元：20万再生を連発）
- 【ステップ数】【要素数】【工程数】（元：3／3／5）
- 【要素の総称】要素をまとめて呼ぶキャッチーな名前（元：頭脳）
- 【メソッド名】独自メソッドの名前（元：市場支配メソッド）
- 【権威の源】ノウハウの出どころ・投資額など（元：父から直伝、1650万円かけて学んだ）
- 【オファー】動画のゴール（元：無料相談）
- 【特典】オファーに付けるプレゼント（元：50大プレゼント）
- 【導線】申し込み方法（元：概要欄かQRコード）
