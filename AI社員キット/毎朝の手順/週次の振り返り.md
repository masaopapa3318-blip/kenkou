# 毎朝の手順｜毎週日曜の振り返り（全部署・ルールづくり）

1週間をふり返って、**修正が多かった所** を見つけ、次から同じ修正をしなくて済むように **新しいルールの案** を出す仕事です。
AIに一度で完璧を求めるのではなく、「やる → 直す → ルールにする → 次から効く」の輪（ループ）を、週に1回まわします。

- 対象は、`.claude/agents/` に入っている **全部の部署**（品質チェック係・監査役もふくむ）
- AIがするのは **案を出すまで**。部署ファイル・CLAUDE.md の書きかえは、社長が「OK」と言ってからです

## 材料：「修正の記録」

ふだんの仕事で、次の2つが起きたら、No.2が `ループ/修正の記録.md` に1行足します（CLAUDE.md の「6. 止め方・知らせ方・記録」）。

- 品質チェック係・監査役に差し戻された
- 社長が「ちがう」「直して」と言った・手で直した

```
日付｜部署｜何が直されたか（1行）｜どう直したか（1行）｜だれが見つけたか（品質チェック係／監査役／社長）
```

この記録がたまるほど、日曜の振り返りが当たるようになります。

## はじめの1回は手で動かす（最初の日曜から）

新しい会話で、次の1行を送ります。

```
No.2として、毎朝の手順/週次の振り返り.md の枠の中のとおりに、今週の振り返りを1回やって。
```

できあがった `ループ/振り返り/日付_週の振り返り.md` を読んで、採用するルール案に「OK」と言います。
定期タスクに登録するのは、**2週目から** です（手で1回まわして、中身に納得してから）。

## 定期タスクに登録する文（枠の中をそのままコピー）
1. Claudeのデスクトップアプリで「定期タスク」の画面を開く（表示名は版によって違うことがあります）
2. 「新しいタスク」（新規）を押す
3. フォルダは、このキットのフォルダを選ぶ
4. 下の枠の中の文をそのまま貼る
5. 時間を「毎週日曜」にする → 保存する

※ パソコンが眠っている時・アプリを閉じている時は動きません。その時間はパソコンを開いておいてください。

```
このフォルダの CLAUDE.md を読んで、そのルールで動いてください。
最初に ループ/振り返り/STOP というファイルがあるか確かめて、あれば何もしないで終わってください（ループ/振り返り/ フォルダがなければ作ってください）。
今週（月曜〜今日）の振り返りを、次の順で1回まわしてください。
① 読む：ループ/修正の記録.md の今週の行／.claude/agents/ の全部の部署ファイルの「直したことの記録」／できあがり/ の今週のファイル／ループ/*/止まった記録.md
② 数える：部署ごとに、今週の修正の数と、似ている修正（同じ理由・同じ言いまちがい・同じ抜け）のまとまりを数える
③ 選ぶ：2回以上くり返した修正を、多い順に3つまで選ぶ。1回だけの修正はルールにしない（「様子見」に書く）
④ 案を出す：選んだ修正ごとに「新しいルールの案」を1行で書く。どこに足すか（部署ファイルの「直したことの記録」か「合格の条件」／全部の部署に効くなら CLAUDE.md の「9. 直したことの記録」）と、根拠（何回・何日・どのファイル）をそえる。今あるルールと同じ・ぶつかるときは、新しく足さずに「今のルールの言い方を変える案」にする
⑤ ループ/振り返り/日付_週の振り返り.md に、次の形で書く
　■ 今週の修正の数（部署ごと）
　■ くり返した修正トップ3と、新しいルールの案（足す場所・1行・根拠）
　■ 様子見（1回だけの修正）
　■ 社長に決めてほしいこと（どの案を採用するか。おすすめつき）
部署ファイル・CLAUDE.md・定期タスクは書きかえない。案を書くだけ。送信・投稿・予約・公開・支払いはしない。
ループ/振り返り/ の記録ファイルへの追記は、確認なしでよい。
ループ/修正の記録.md が無い時、または今週の行が0件の時は、「今週は修正の記録が0件でした」と1行書いて終わってください。
1回の上限は20分。超えそうなら、途中でも、ループ/振り返り/止まった記録.md に「時間切れ・どこまでやったか」を1行書いて終わってください。
うまくいかなかったら、ループ/振り返り/止まった記録.md に「日時・どこで止まったか・理由」を1行書いて終わってください。
終わったら、何を作ったかを3行で書いてください。
```

- おすすめの時間：**毎週日曜 17:00**
- 時間は、パソコンの前にいる時間にする（確認の画面が出ると、だれもいない時間はそこで止まり、次の回も動かないことがある）
- 最初の1回は、パソコンの前で「今すぐ実行」を押す。確認の画面が出たら読む。このフォルダの中のファイル（`.md`）を作る・書きかえる確認なら「許可」。send・post・publish・schedule・reserve・create_event・delete・remove・pay・purchase の文字が見えたら「拒否」
- 「いつも許可」は押さない（押してしまったら、そのタスクをいったんオフにする）

## 案を採用するとき（月曜の朝など、社長が見る）

```
ループ/振り返り/ の最新の振り返りを見せて。案の〇番と〇番を採用します。
足す前に、どのファイルのどこに何を足すかを見せて。わたしが「OK」と言ったら保存して。
```

- 採用しなかった案は、そのままでOK（次の週にまたくり返したら、もう一度出てきます）
- ルールを足したら、翌週の振り返りで「その修正が減ったか」も見ます

## 止め方
- **少し止める**：`ループ/振り返り/STOP` という空のファイルを置く。Claudeに「ループ/振り返り/STOP を作って」と頼めば作ってくれます
- **ずっと止める**：アプリの定期タスクの画面で、そのタスクをオフにする
- いま動いている途中なら、停止ボタン（■）か esc キー

## 見るところ
| 見る所 | こうなっていればOK |
|---|---|
| `ループ/振り返り/` | 日曜のあとに、新しい振り返りのファイルが1つ増えている |
| 振り返りのファイル | ルール案に「足す場所・1行・根拠（何回・何日）」がそろっている |
| 部署ファイル・CLAUDE.md | あなたが「OK」と言うまで、書きかわっていない |
| `ループ/振り返り/止まった記録.md` | 空、またはファイルがない |
